## Milestone 0: plan before you code

Write down, on paper or in a `PLAN.md`:

**Pages**

| Page | Who | Does |
| --- | --- | --- |
| `index.php` | everyone | shows plans, contact form |
| `register.php` | everyone | creates an account |
| `login.php` | everyone | password step |
| `setup_2fa.php` / `verify_2fa.php` | half-logged-in users | Authenticator step |
| `dashboard.php` | logged-in users | landing page |
| `admin.php` | admins | users list, plans CRUD, messages |
| `logout.php` | logged-in users | code, then log out |

## Milestone 1: folder and database

Create `C:\xampp\htdocs\kraft\install.sql`:

```sql:install.sql
CREATE DATABASE IF NOT EXISTS kraft CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
USE kraft;

CREATE TABLE IF NOT EXISTS users (
  id INT AUTO_INCREMENT PRIMARY KEY,
  email VARCHAR(150) NOT NULL UNIQUE,
  password_hash VARCHAR(255) NOT NULL,
  role ENUM('member','admin') NOT NULL DEFAULT 'member',
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB;

CREATE TABLE IF NOT EXISTS plans (
  id INT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(50) NOT NULL,
  price_eur DECIMAL(6,2) NOT NULL
) ENGINE=InnoDB;

INSERT INTO plans (name, price_eur) VALUES ('Basic', 24.90), ('Premium', 39.90), ('Student', 19.90);
```

Import it in phpMyAdmin (**Import** tab) or with:

```powershell
C:\xampp\mysql\bin\mysql.exe -u root < C:\xampp\htdocs\kraft\install.sql
```

**Checkpoint:** phpMyAdmin shows the database `kraft` with two tables, and `plans` has three rows.

## Milestone 2: config.php

```php:config.php
<?php
// Shared by every page.
$pdo = new PDO('mysql:host=127.0.0.1;dbname=kraft;charset=utf8mb4', 'root', '', [
    PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    PDO::ATTR_EMULATE_PREPARES => false,
]);
session_set_cookie_params(['httponly' => true, 'samesite' => 'Strict']);
session_start();

function h($s) { return htmlspecialchars((string)$s, ENT_QUOTES); }
function go($url) { header("Location: $url"); exit; }
function me() { return $_SESSION['user'] ?? null; }
function require_login() { if (!me()) go('login.php'); }
function require_admin() {
    require_login();
    if (me()['role'] !== 'admin') { http_response_code(403); exit('Admins only.'); }
}
```

No closing `?>`: this file only contains PHP, and a stray space after `?>` would break redirects.

**Checkpoint:** create `test.php` with `<?php require 'config.php'; echo 'OK';` and open `http://localhost/kraft/test.php`. You see **OK**. If you see a PDO error, check that MySQL is running and the database name matches. Then delete `test.php`.

## Milestone 4: registration

```php:register.php
<?php
require 'config.php';
$msg = '';
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $email = trim($_POST['email'] ?? '');
    $pass  = $_POST['password'] ?? '';

    if (!filter_var($email, FILTER_VALIDATE_EMAIL)) $msg = 'Invalid email.';
    elseif (strlen($pass) < 8)                      $msg = 'Password needs at least 8 characters.';
    else {
        // The first account becomes the admin.
        $role = $pdo->query('SELECT COUNT(*) FROM users')->fetchColumn() == 0 ? 'admin' : 'member';
        try {
            $pdo->prepare('INSERT INTO users (email, password_hash, role) VALUES (?, ?, ?)')
                ->execute([$email, password_hash($pass, PASSWORD_DEFAULT), $role]);
            go('login.php?registered=1');
        } catch (PDOException $e) {
            $msg = $e->getCode() == 23000 ? 'This email is already registered.' : 'Registration failed.';
        }
    }
}
?>
<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><title>Join</title></head>
<body>
  <h1>Join Kraft</h1>
  <?php if ($msg): ?><p style="color:#c00"><?= h($msg) ?></p><?php endif; ?>
  <form method="post">
    <label>Email <input type="email" name="email" value="<?= h($_POST['email'] ?? '') ?>" required></label><br>
    <label>Password <input type="password" name="password" minlength="8" required></label><br>
    <button>Create account</button>
  </form>
</body></html>
```

## Milestone 5: login, dashboard, logout (password only)

First a working login **without** 2FA. We add the second factor in Milestone 8, and the structure is designed so that is a small change.

```php:login.php
<?php
require 'config.php';
$msg = '';
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $s = $pdo->prepare('SELECT id, email, role, password_hash FROM users WHERE email = ?');
    $s->execute([trim($_POST['email'] ?? '')]);
    $u = $s->fetch();
    if ($u && password_verify($_POST['password'] ?? '', $u['password_hash'])) {

        $_SESSION['user'] = ['id' => $u['id'], 'email' => $u['email'], 'role' => $u['role']];
        go('dashboard.php');

?>

    <label>Email <input type="email" name="email" required></label><br>
    <label>Password <input type="password" name="password" required></label><br>

  </form>
</body></html>
```

## Milestone 7: CRUD for plans

Add action handling at the top of `admin.php`, right after the `$t` line:

```php
$err = '';
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $id = (int)($_POST['id'] ?? 0);
    switch ($_POST['do'] ?? '') {
        case 'add_plan':
            $name = trim($_POST['name'] ?? '');
            $price = $_POST['price'] ?? '';
            if ($name === '' || !is_numeric($price)) { $err = 'Name and numeric price required.'; break; }
            $pdo->prepare('INSERT INTO plans (name, price_eur) VALUES (?, ?)')->execute([$name, $price]);
            break;
        case 'delete_plan':
            $pdo->prepare('DELETE FROM plans WHERE id = ?')->execute([$id]);
            break;
    }
    if (!$err) go("admin.php?t=$t");
}
```

And the plans tab, before the final `</body>`:

## Milestone 8: Google Authenticator

Now the second factor. Copy `totp.php` from the course files (`Week3_Login/GoogleAuth/totp.php`) and `qr_fcm.js` (from `FCM_GoogleAuth` or the finished `fitness_center`) into `kraft/`.

### 8a. Table and config

```sql
USE kraft;
CREATE TABLE user_2fa (
  user_id INT PRIMARY KEY,
  secret_base32 VARCHAR(64) NOT NULL,
  enabled TINYINT(1) NOT NULL DEFAULT 0,
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
) ENGINE=InnoDB;
```

Add to `config.php`:

```php
require_once __DIR__ . '/totp.php';
const ISSUER = 'Kraft Fitness';

function finish_login($u) {
    session_regenerate_id(true);
    $_SESSION = ['user' => ['id' => $u['id'], 'email' => $u['email'], 'role' => $u['role']]];
    go('dashboard.php');
}

function code_ok($uid, $code, $enabledOnly = true) {
    global $pdo;
    $s = $pdo->prepare('SELECT secret_base32 FROM user_2fa WHERE user_id = ?' . ($enabledOnly ? ' AND enabled = 1' : ''));
    $s->execute([$uid]);
    $secret = $s->fetchColumn();
    return $secret && verify_totp($secret, $code);
}
```

### 8b. Change the login: password → "pre" state

In `login.php`, replace the two lines that set `$_SESSION['user']` and go to the dashboard with:

```php
        $_SESSION = ['pre' => ['id' => $u['id'], 'email' => $u['email'], 'role' => $u['role']]];
        $s = $pdo->prepare('SELECT enabled FROM user_2fa WHERE user_id = ?');
        $s->execute([$u['id']]);
        go($s->fetchColumn() ? 'verify_2fa.php' : 'setup_2fa.php');
```

### 8c. Setup page

## Milestone 10: lockout

Add the columns:

```sql
ALTER TABLE users ADD failed_count TINYINT NOT NULL DEFAULT 0, ADD locked_until DATETIME DEFAULT NULL;
```

Add to `config.php`, then use it in `code_ok` (count failures, reset on success) and in `login.php` (refuse while locked, count wrong passwords). Compare with the finished version in the [walkthrough](/wiki/fitness-walkthrough#5-lockout).

```php
const MAX_FAILS = 5, LOCK_MINUTES = 15;

function is_locked($uid) {
    global $pdo;
    $s = $pdo->prepare('SELECT locked_until > NOW() FROM users WHERE id = ?');
    $s->execute([$uid]);
    return (bool)$s->fetchColumn();
}

function register_fail($uid) {
    global $pdo;
    $pdo->prepare('UPDATE users SET failed_count = failed_count + 1,
        locked_until = IF(failed_count >= ?, NOW() + INTERVAL ' . LOCK_MINUTES . ' MINUTE, locked_until),
        failed_count = IF(failed_count >= ?, 0, failed_count) WHERE id = ?')
        ->execute([MAX_FAILS, MAX_FAILS, $uid]);
}
```

**Checkpoint:** five wrong passwords in a row, then the right one: still refused. In phpMyAdmin set `locked_until = NULL`: login works again.
