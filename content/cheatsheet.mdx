## PHP basics

[Full article](/wiki/php-basics)

```php
<?php

```

| Task | Code |
| --- | --- |
| Inspect a value | `var_dump($x);` / `print_r($arr);` |
| Convert type | `(int) $x`, `(float) $x`, `(string) $x` |
| String length / trim | `strlen($s)`, `mb_strlen($s)`, `trim($s)` |
| Replace / contains | `str_replace('a', 'b', $s)`, `str_contains($s, '@')` |
| Format a price | `number_format(1500.5, 2, ',', '.')` → `1.500,50` |
| Date | `date('d.m.Y H:i')`, `date('Y')` |

## Sessions and login

[Sessions](/wiki/sessions-login) · [Hashing & 2FA](/wiki/passwords-2fa)

```php
session_start();                               // every page, before output
$_SESSION['user'] = ['id' => 8, 'role' => 'admin'];
session_regenerate_id(true);                   // after login

$hash = password_hash($pass, PASSWORD_DEFAULT);

$_SESSION = []; session_destroy();             // logout
setcookie(session_name(), '', time() - 3600, '/');
```

## SQL

[Full article](/wiki/databases-sql)

```sql
CREATE TABLE plans (
  id INT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(50) NOT NULL,
  price_eur DECIMAL(6,2) NOT NULL
) ENGINE=InnoDB;

ALTER TABLE plans ADD description VARCHAR(150) NOT NULL DEFAULT '';

INSERT INTO plans (name, price_eur) VALUES ('Basic', 24.90);
SELECT name, price_eur FROM plans WHERE price_eur < 30 ORDER BY price_eur DESC LIMIT 10;
SELECT * FROM members WHERE last_name LIKE '%mid%';
UPDATE plans SET price_eur = 26.90 WHERE id = 1;
DELETE FROM contacts WHERE id = 15;

SELECT m.first_name, p.name AS plan
FROM members m JOIN plans p ON p.id = m.plan_id;          -- LEFT JOIN keeps unmatched left rows

SELECT p.name, COUNT(m.id) FROM plans p LEFT JOIN members m ON m.plan_id = p.id GROUP BY p.id, p.name;
```

| Type | For |
| --- | --- |
| `INT`, `TINYINT` | IDs, counts, flags |
| `DECIMAL(6,2)` | money |
| `VARCHAR(n)`, `TEXT` | text |
| `DATE`, `DATETIME`, `TIMESTAMP` | dates and times |
| `ENUM('a','b')` | one of a fixed list |

## Security in one table

[Full article](/wiki/web-security)

| Threat | Defence |
| --- | --- |
| SQL injection | Prepared statements |
| XSS | `htmlspecialchars` on every output |
| CSRF | POST for changes, `SameSite` cookies, CSRF tokens |
| Broken access | Guard + `exit` on every protected file |
| Password leaks | `password_hash` / `password_verify` |
| Brute force | Lockout / rate limiting, 2FA |
| Session fixation | `session_regenerate_id(true)` after login |
